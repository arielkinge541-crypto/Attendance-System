Every grant or revocation of authority by the Super Admin, creation or removal of an Admin account, removal of a member, and every username change, password change, and password reset is logged here: who did it, to whom, and at what time. Passwords themselves are never written to this log.

Admin Management Super Admin only

This is the only place where authority can be granted or revoked. An Admin cannot grant authority to others and cannot see this screen. As Super Admin, you can also change the username and password of any Admin or user account here, or reset a password to a temporary one. An Admin can only change their own username and password, and a member can only change their own password (in My Account). Every change is logged in the Audit Log above.

User Profiles — Members

Every member has their own Profile Account: their own details, profile picture, and attendance history. The Super Admin and Admin can edit details and upload a picture for a member; a member can only change their own picture and can only see their own records. The Super Admin and Admin can also see each member's check-in photo proof in their profile (and in the Audit Log) — tap it to view it larger; a member only ever sees their own proof.
